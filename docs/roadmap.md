# Roadmap

Phases are listed in order. **No dates are given**, because none have been committed to. A phase is marked done only when it is verifiably done.

Legend: ✅ done · 🔨 in progress · ⬜ not started

## Phase 0: Presence

- ✅ Public website on initiate.site
- ✅ Live chain figures: block height, gas, value locked, 90-day history
- ✅ Live token sightings on Robinhood Chain
- ✅ Register of external facts, with inert placeholders for unpublished items
- ✅ Automated checks for layout, accessibility, motion preferences and data handling
- ✅ Project documents

## Phase 1: Design

- 🔨 Specify the launch flow end to end
- 🔨 Specify the set of counterparts and how each is priced
- ⬜ Specify the private swap route, its guarantees and its limits
- ⬜ Publish the design for public comment

## Phase 2: Build

- ⬜ Launch contracts
- ⬜ Pairing and pricing logic
- ⬜ Private swap path
- ⬜ Launcher interface

## Phase 3: Assurance

- ⬜ Independent review of every contract that holds value
- ⬜ Public test period on a test network
- ⬜ Incident and disclosure process rehearsed (see [security policy](../.github/SECURITY.md))

## Phase 4: Release

- ⬜ Publish the contract address in the register, simultaneously on the site, in this repository and on official channels
- ⬜ Open the launcher
- ⬜ Announce official social accounts

## Phase 5: Growth

- ⬜ Broader counterpart support
- ⬜ Tooling for creators and integrators
- ⬜ Ongoing review of privacy protections as the chain evolves

## How to read progress

The website's Records section is the source of truth for what is public. If an item there says *Not yet*, the matching roadmap item has not shipped.
