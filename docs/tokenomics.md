# Tokenomics

**Status:** no Initiate token has been published. There is no contract address on record.

This page exists to be clear about that, and to set the standard future numbers will be held to. It contains no supply, allocation or price figures because none have been announced. Any figure you see elsewhere attributed to Initiate is not from this project.

## What tokens the protocol concerns

Initiate is a launch protocol. The tokens that matter most are the ones creators mint through it, each paired with a counterpart the creator chooses. Any token of Initiate's own is a separate question and is undecided.

## Standard for publication

When a figure is announced it will be published with:

1. The exact number and unit, never a range or a percentage of an unstated total.
2. The on-chain address or transaction that proves it, where one exists.
3. The date it took effect, only once it has taken effect.
4. A plain statement of who can change it and how.

## Questions to be answered before any token exists

- Is there a native token at all, or does the protocol run on fees in existing assets?
- If fees exist, who receives them and on what schedule?
- What, if anything, is locked, by whom, and for how long?
- What can the deployers change after launch, and what is immutable?

## Verifying anything

The only authoritative record is the register in the website source (`src/records.js`) and the site's Records section. If the contract address is not listed there, it is not official.
